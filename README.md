# Essence Wholesale Foods

A responsive, buildless website for Essence Wholesale Foods, Unit 28, Enterprise Park Industrial Estate, Woodbourn Road, Sheffield S9 3JL, United Kingdom.

Run `npm run dev` to preview at http://127.0.0.1:4173. Run `npm run check` for JavaScript syntax checks. The deployable website is in `dist/` and requires no dependencies or build step.

Includes category filtering, live product search, a device-local enquiry list, text export, clipboard copy, a WhatsApp draft handoff, tap-to-call, mobile navigation, a privacy notice and Google Maps directions. Enquiries are not submitted to a server, and no orders or payments are processed.

Product categories and stock photography are illustrative, awaiting owner confirmation. Business phone / WhatsApp: +44 7402 342704. Add verified product details, prices, email and opening hours before a customer-facing launch. No delivery promises, testimonials, stock counts or prices are invented.

Photography: Unsplash. Assets are downloaded into `dist/assets/`. Typefaces: DM Sans and Manrope, served by Google Fonts. The location graphic is illustrative, with Google Maps used for real directions.
